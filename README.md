Dashboard de Performance Financeira: Vendas, Custos e Margem de Lucro
Este projeto apresenta o desenvolvimento de um dashboard estratégico para monitoramento de indicadores financeiros (KPIs) de uma operação comercial. O foco principal é a análise detalhada da relação entre receita, custos operacionais e a rentabilidade real do negócio.

Objetivo do Projeto
O objetivo deste projeto foi transformar dados transacionais em uma ferramenta de gestão visual que permita identificar rapidamente quais produtos e períodos geram a melhor margem de lucro, facilitando a otimização de custos e o ajuste de estratégias de preço.

Indicadores de Desempenho (KPIs) Analisados
Faturamento Total: Valor bruto gerado pelas vendas no período.

Custo Total: Somatória de custos diretos e indiretos associados aos produtos vendidos.

Margem de Lucro: Diferença percentual e nominal entre a receita e os custos.

Volume de Vendas por Categoria: Identificação dos produtos com maior giro de estoque.

Evolução Temporal: Análise comparativa de lucro e custos ao longo do tempo.

Funcionalidades Técnicas
Modelagem de Dados: Estruturação de tabelas para garantir a integridade dos cálculos financeiros.

Cálculos de Medidas: Utilização de fórmulas para extrair margens de lucro dinâmicas conforme os filtros aplicados.

Visualização de Dados: Construção de gráficos de série temporal, cartões de indicadores e tabelas de composição de margem.

Filtros Interativos: Segmentação da análise por data, categoria de produto e região.

Tecnologias Utilizadas
Power BI: Para a criação do dashboard e visualização de dados.

Excel / CSV: Fontes de dados utilizadas para o processamento.

Metodologia Aplicada
extração e tratamento dos dados brutos (limpeza de registros).

Definição das regras de negócio para cálculo de margem e custos.

Criação da estrutura visual (layout) focada em facilitar a leitura executiva.

Validação dos resultados financeiros apresentados.
